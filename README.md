# GBA Wellness Club — site

Statik site. Derleme adımı yok; `index.html` doğrudan yayınlanır.

- `index.html` — sitenin tamamı (HTML + CSS + JS tek dosyada)
- `img/` — görseller
- WhatsApp numarası `index.html` içinde `var WHATSAPP = "..."` satırında
- Site adresi: meta etiketlerinde ve `sitemap.xml` / `robots.txt` içinde

Değişiklikler bu depoya push edildiğinde Netlify otomatik yayına alır.
